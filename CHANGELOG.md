# Changelog

## 1.6.x (unreleased)
- Chase boost: the spider speeds up as it closes in, only with line of sight.
- Web alert: stepping in a web sends the spider sprinting to it, faster the further away it is.
- Waiting camouflage: a motionless spider dissolves using the Barber's dissolve effect.
- Victims hang at a set height above the floor so they can always be reached.
- More webs, placed more often, over a wider patrol area.
- Safety nets for spiders that cannot find a hanging spot (carry timeout, wall reach).

## 1.0.0
- First release: paralyse, wrap, drag and hang; cut-down rescue; multiplayer sync; spider camera; F9 emergency release.
